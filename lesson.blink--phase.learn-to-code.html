این همان فایل اصلی و بدون بازنویسی است. هر بخش را با توضیح کوتاهش بخوان.

// Fixture: external LED on digital pin 13.
const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}
دریافت فایل اصلی

در Windows، کلیپ‌بورد ممکن است پایان خط‌های LF را به CRLF تبدیل کند. برای بایت‌های دقیق، فایل اصلی را دریافت کن.

setup()

این بخش فقط یک بار، هنگام شروع برنامه اجرا می‌شود.

pinMode(13, OUTPUT)

پین D13 را برای فرستادن فرمان آماده می‌کند.

digitalWrite(13, HIGH)

ولتاژ پین D13 را بالا می‌برد و LED روشن می‌شود.

delay(1000)

برنامه ۱۰۰۰ میلی‌ثانیه، یعنی یک ثانیه، صبر می‌کند.

digitalWrite(13, LOW)

ولتاژ پین را پایین می‌آورد و LED خاموش می‌شود.
